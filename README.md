# 折りGO ローカルデモ

提供されたsrc.zip/public.zipを元にしたReact + Viteデモ。

## 起動

```sh
pnpm install
pnpm dev
```

http://127.0.0.1:5173/ を開く。

1. やることを書いて「折り紙にする」。
2. http://127.0.0.1:5173/#alarm を開き、「朝を体験する」→「カメラなしでためす」→「ここから始める（デモ）」。
3. 6秒の追いかけっこ後、「近づく（デモ）」を6回。
4. 0.85秒の待機後に「つかまえる」。
5. 折り紙を開き、スワイプまたはボタンで3回ひらく。

デモの移動は1操作あたり0.3mの仮想距離。カメラ・歩行検出は使用しない。音は初期状態でオフ。上部で音の切り替えと終了ができる。タスクと捕獲はブラウザ内に保存する。

## 確認

```sh
pnpm build
pnpm exec tsc --noEmit
```

iOSアプリ化の要件はdocs/ios-requirements.md。iOS実機へのインストールと歩行判定、AlarmKitは未実装・未検証。
