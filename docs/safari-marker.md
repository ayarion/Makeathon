# Safariの鬼ごっこデモ

印刷・物理マーカー・床認識・動作センサー許可は不要。カメラを許可し、床を写して「ここで決定」で開始する。

鶴が奥へ逃げる演出を30秒表示した後、鶴が止まって「タップでつかまえよう」に切り替わる。鶴をタップすると捕獲する。残り時間バーは表示しない。自動では捕獲せず、画面非表示や一時停止中は時間を進めない。これは時間で進むカメラデモであり、実際の接近は測定しない。

全画面背景とsafe-areaの修正は維持する。WebXR経路も30秒後に動物のタップで捕獲可能になる。

`node --test tests/marker-proximity.test.mjs`（履歴のためファイル名維持）で30秒後の解放、停止中の時間、早いタップの拒否、バーがないことを確認する。
