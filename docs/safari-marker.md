# Safariでの接近と捕獲

公開サイトの「印刷用マーカーを開く」からA4・倍率100%で印刷する。黒い外枠は一辺18cm。紙を明るい床に固定し、約2m離れてマーカー全体をカメラに写し、「ここで決定」を押す。鶴がいるマーカーまで歩いて近づき、鶴そのものをタップすると捕獲する。マーカーは動かさない。

Safariのカメラ経路は js-aruco2 2.0.0（MIT、著作権表示は ar-engine.js 内）で画像を端末内だけで処理する。録画・画像送信は行わない。既知サイズのマーカーの姿勢から床面方向の距離を推定する。カメラ内部パラメータは未較正で、値は概算。端末の接近を判定するもので足の運動・離床そのものを測定するものではない。

開始には推定距離1.8〜4mの安定した検出が必要。捕獲は開始位置から1.2m以上近づき、推定水平距離65cm以内で検出が安定した場合にのみ可能。650msは近距離検出の安定確認であり、追跡時間によって解放する制限時間ではない。検出の欠落・古いフレーム・急激な姿勢変化では捕獲不可。1.5秒超の追跡喪失や画面非表示後は開始位置を設定し直す。

鶴は床マーカーの位置に固定して投影し、逃げる向きの走りを表示する。接近に応じて投影サイズが変わる。追跡がない場合、鶴を隠す。残り時間バー、時間経過による捕獲、画面のどこでも捕獲できる処理はない。

全画面の体験・開封はSafariのmodal dialog top layerを使わず、通常のfixed dialogを上下0・高さ100%で表示する。html/bodyも同じ背景色にし、safe-area-insetで操作領域を確保する。背景の切れを避けるため、他のモーダルは一時的に閉じてから表示し、終了時に復元する。

## 検証

`node --test tests/marker-proximity.test.mjs` は静止・接近・追跡喪失・姿勢ジャンプ・古い観測・疑似画像の検出と姿勢推定を検証する。buildとTypeScript確認に加え、ローカルの仮想カメラで操作を確認する。iPhone 17 Proの実カメラ、SafariのURL欄伸縮、印刷物の照明・ブレは実機で未検証。
