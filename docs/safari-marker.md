# Safariでのマーカーなし接近・捕獲

印刷や物理マーカーは不要。カメラと動きの検出を許可し、約2m先の模様のある明るい床をゆっくり見渡す。床の認識後に「ここで決定」を押し、逃げた鶴まで歩いて近づいて鶴そのものをタップする。

Safariでは8th Wall engine-binary 1.0.0のSLAMを使い、カメラの位置と床面を追跡する。公式の変更していない配布物をCDNから読み込み、同梱の著作権・ライセンス表示を保持する。ネイティブWebXRが使える端末は既存のWebXR経路を使う。

開始には1.5〜3.5m先の床面の安定した認識が必要。鶴は開始地点より奥の範囲を逃げる。捕獲条件は開始地点から端末が水平に1.2m以上移動し、鶴から水平65cm以内で追跡が650ms安定していること。650msは観測の安定確認で、待ち時間による解除ではない。鶴の3D形状をタップした場合のみ捕獲する。時間バーや時間経過による自動捕獲はない。

追跡が不確かになったら鶴を隠し、捕獲を禁止する。1.5秒超の追跡喪失や画面非表示からの再開では床を設定し直す。カメラ位置の急変も設定を無効にする。端末の移動を測っているため、足の運動そのものを保証するものではない。無地・暗い・反射する床では認識しづらい。

全画面の体験・開封はSafariのmodal dialog top layerを使わず、通常のfixed dialogを上下0・高さ100%で表示する。html/bodyも同じ背景色にし、safe-area-insetで操作領域を確保する。

## 検証

`node --test tests/marker-proximity.test.mjs`（過去のファイル名を維持）は静止、接近、追跡喪失、位置ジャンプ、古い観測、時間による捕獲の禁止を検証する。build、TypeScript確認、ブラウザでの読み込みと表示の確認を行う。iPhone 17 Proの実カメラによる床認識・位置精度は実機で未検証。
